# Domain Model

## Core Principle

A user may have multiple roles simultaneously.

## Project

Project is the central business entity of Creastrix.

### Identity

- ID
- Name
- Description
- Slug
- Owner
- Status
- Created At
- Updated At

### Status

A project can have one of the following statuses:

- Draft
- Published
- Archived

### Capabilities

- Publish
- Archive

### Ownership

A project belongs to an owner.

An owner can be:
- User
- Organization
